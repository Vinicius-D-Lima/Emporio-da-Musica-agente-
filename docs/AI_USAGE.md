| 2026-11-03 | 10 — intent classifier | Implement multi-label classification with rules and an LLM only for doubtful cases. | Rules for greetings, store data, policies, accessories and out-of-scope subjects; an optional LLM callback for unrecognised messages. | Accessories also receive `fora_assunto`; without a callback, an unrecognised message returns `[]`; invalid output or a callback failure is explicit. |
| 2026-11-03 | 11 — agent loop | Implement function calling and execute the tools in the agent cycle. | Added a dispatcher with Pydantic schemas, persisted history and an injectable loop; safe errors go back to the model, five-round limit and a final call without tools. | The agent uses the configured provider when it is not given an injected model; after the limit, the model cannot request more tools. |
| 2026-11-03 | 12 — CLI | Complete the pending steps up to Step 12. | The interactive CLI was connected to the configured provider, keeps the conversation, accepts `--conversa ID` and `--debug`. | Single-line input per message; the provider can be injected in tests. |
| 2026-11-03 | 15 — adversarial scenarios | Create security and consistency tests without comparing full answers. | Prepared 24 opt-in LLM scenarios and deterministic tests that check that reading an order without verification is blocked and that customers are isolated from each other. | The user chose scenarios A01–A24 and asked that the real LLM only run on explicit request. The scenarios with a real provider were not executed at this stage. |
| 2026-11-04 | 15 — scenario adjustments with real providers | Analyse failures observed in the adversarial scenarios run with real providers. | A01, A02, A04, A10, A13 and A14 accept a safe refusal without a tool but still forbid unconfirmed data; store recommendations are checked against the configured list; the prompt supplies that list and tells the agent to reuse the already verified identity to call `status_pedido`. | The Gemini/Groq 429 limits must be handled operationally: run a few scenarios at a time and wait for the quota to renew.
